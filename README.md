# Kupi Club dashboard demo

Interactive demo of the proposed Kupi Club analytics screens (Обзор, Драйверы, Товары,
Блогеры, Ролики). Single self-contained HTML file, no build step.

All numbers are synthetic: generated on page load from a seeded random generator, so the
demo is stable between visits but does not reflect any real client data.

Source of truth lives in the private `beautycevtika-kit` project (`kupiklub/dashboard-demo.html`);
`index.html` here is that file wrapped in a full HTML document for GitHub Pages.
